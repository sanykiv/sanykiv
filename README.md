# Александр Киваев

Аналитик данных · Python · SQL · Power BI · A/B-тесты

Пришёл в аналитику из управления производством ресторана: отвечал за себестоимость,
закупки и ФОТ, а потом разобрал реальные данные этого же ресторана как аналитик.
В проектах сначала формулирую вопрос бизнеса, потом проверяю, не обманывают ли меня данные.

**Стек:** Python (pandas, matplotlib, seaborn, statsmodels) · SQL (CTE, оконные функции) ·
Power BI (DAX) · Excel · Git

## Проекты

**[Online Retail II](https://github.com/sanykiv/online-retail-analysis)** — на ком держится выручка онлайн-магазина
RFM-сегментация 5 852 клиентов и когорты за 25 месяцев: 25% клиентов дают 69% выручки,
большинство новичков теряется после первой покупки. Python · SQL · Power BI

**[A/B-тест рекламной кампании](https://github.com/sanykiv/marketing-ab-test)** — сработала ли реклама и где
588 тыс. пользователей: +0,77 п.п. к конверсии (p < 0,001), около 4 300 дополнительных покупок;
эффект почти целиком у активных пользователей. Python · statsmodels

**[Анализ данных ресторана](https://github.com/sanykiv/restaurant-analysis)** — где ресторан теряет деньги
Ревизия склада: недостача 44 335 ₽ и 55 позиций с отрицательным остатком; фудкост 56 блюд по ТТК;
загрузка зала по 1 688 броням. Python · pandas · pdfplumber
